### Design System

| Token | Usage |
|---|---|
| `--color-primary` | #1a6b3a (light) / #2ecc71 (dark) |
| `--font-sans` | Plus Jakarta Sans |
| `--font-display` | Fraunces (serif for headings) |
| `--text-hero` | Clamp 2.5rem → 4.5rem |
| `--space-*` | 4px → 128px scale |
| `--shadow-*` | 4 shadow levels |

### Theming

Supports **light** & **dark** mode via `data-theme` attribute. Toggle with the sun/moon button in the navbar. Respects `prefers-color-scheme` on first load. Reduced motion is respected via `prefers-reduced-motion`.
